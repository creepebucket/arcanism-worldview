# 发魔产线

> 前期发魔产线: 燃烧煤炭产生蒸汽, 驱动转换机产出魔力。
> 下文产速均指魔力产出速率。

## 规划

### 1. 燃煤锅炉 (共用)

发魔产线的能量来源。煤炭在炉膛内燃烧, 将水加热为高温高压蒸汽 (500°C / 10 MPa), 供给下游转换机。

**机制**:
- 输入: 煤炭 + 水
- 输出: 高温高压蒸汽
- 锅炉效率: 85% (不完全燃烧 ~3%, 炉壁散热 ~5%, 烟气热损 ~7%)

**运行参数**:

| 参数 | 值 |
|------|-----|
| 煤炭热值 | 25 MJ/kg |
| 锅炉效率 | 85% |
| 每kg煤产出蒸汽能 | 21.25 MJ |
| 蒸汽温度 | 500°C (773 K) |
| 蒸汽压力 | 10 MPa |

### 2. 蒸汽轮机 (产 m)

蒸汽通过轮机叶片膨胀做功, 将热能转化为机械旋转, 再通过魔力极化结构产出 m 魔力。

**机制**:
- 输入: 高温高压蒸汽 (来自锅炉)
- 输出: m 魔力 + 乏汽 (排入冷凝器/大气)
- 热效率 (蒸汽→机械): 38% (Rankine 循环, 小型机组)
- 机械功→m 极化效率: 85%

**总效率 (煤→m)**: 85% × 38% × 85% = **27.5%**

### 3. 泄压阀 (产 p)

高压蒸汽通过节流口/阀门, 压力差驱动 p 魔力极化。蒸汽膨胀产生的 pV 功被魔力极化结构捕获。

**机制**:
- 输入: 高温高压蒸汽 (来自锅炉)
- 输出: p 魔力 + 降压蒸汽
- 蒸汽能→pV 功提取: 35% (等熵膨胀条件下压力能做功比例)
- pV 功→p 极化效率: 85%

**总效率 (煤→p)**: 85% × 35% × 85% = **25.3%**

### 4. 热交换机 (产 t)

蒸汽在换热器内降温, 温度梯度直接极化 t 魔力粒子。温差是 t 魔力的天然驱动力。

**机制**:
- 输入: 高温高压蒸汽 (来自锅炉)
- 输出: t 魔力 + 冷凝水
- 热焓提取: 44% (受 Carnot 限制: 1−T_c/T_h = 1−300/773 ≈ 61%, 叠加换热器传热损失 ~30%)
- 温差→t 极化效率: 85%

**总效率 (煤→t)**: 85% × 44% × 85% = **31.8%**

> t 路线是三条路线中最高效的 —— 热量本身就是 t, 不需要转化为机械功或压力功, 中间损耗最少。

## 计算

> 按当前参数, 基于热力学与工程经验公式计算每台机器的 1MW 耗煤量与运行参数。

### 核心参数

| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 煤炭热值 | Q_coal | 25 | MJ/kg |
| 锅炉效率 | η_b | 0.85 | — |
| 每kg煤蒸汽能 | E_steam | 21.25 | MJ/kg |
| 水的气化+过热焓 | Δh | 3.4 | MJ/kg (水) |

### 1. 蒸汽轮机 (m) — 1 MW

**能量链**: 煤 → 蒸汽能 → 机械功 → m 魔力

```
η_total = η_b × η_turbine × η_pol
       = 0.85 × 0.38 × 0.85
       = 27.5%
```

**耗煤量**:

```
P_in = P_out / η_total = 1 MW / 0.275 = 3.64 MW (煤化学能)
ṁ_coal = P_in / Q_coal = 3.64 × 10⁶ / (25 × 10⁶) = 0.1456 kg/s
       = 8.74 kg/min = 524 kg/h
```

**耗水量**:

```
蒸汽能流量 = 3.64 × 0.85 = 3.09 MW (蒸汽热能)
ṁ_steam = 3.09 / 3.4 = 0.909 kg/s
ṁ_water = 0.909 kg/s = 54.5 kg/min ≈ 54.5 L/min
```

**汇总**:

| 项目 | 值 |
|------|-----|
| 目标出力 | 1 MW (m 魔力) |
| 总效率 | 27.5% |
| 耗煤量 | **8.74 kg/min** (≈ 0.146 个/s) |
| 耗水量 | **54.5 L/min** |
| 输入煤化学能 | 3.64 MW |

### 2. 泄压阀 (p) — 1 MW

**能量链**: 煤 → 蒸汽能 → pV 功 → p 魔力

```
η_total = η_b × η_pv × η_pol
       = 0.85 × 0.35 × 0.85
       = 25.3%
```

**耗煤量**:

```
P_in = 1 MW / 0.253 = 3.95 MW
ṁ_coal = 3.95 × 10⁶ / (25 × 10⁶) = 0.158 kg/s
       = 9.49 kg/min = 569 kg/h
```

**耗水量**:

```
蒸汽能流量 = 3.95 × 0.85 = 3.36 MW
ṁ_water = 3.36 / 3.4 = 0.988 kg/s = 59.3 L/min
```

**汇总**:

| 项目 | 值 |
|------|-----|
| 目标出力 | 1 MW (p 魔力) |
| 总效率 | 25.3% |
| 耗煤量 | **9.49 kg/min** (≈ 0.158 个/s) |
| 耗水量 | **59.3 L/min** |
| 输入煤化学能 | 3.95 MW |

### 3. 热交换机 (t) — 1 MW

**能量链**: 煤 → 蒸汽能 → 温差 → t 魔力

```
η_total = η_b × η_hx × η_pol
       = 0.85 × 0.44 × 0.85
       = 31.8%
```

**耗煤量**:

```
P_in = 1 MW / 0.318 = 3.14 MW
ṁ_coal = 3.14 × 10⁶ / (25 × 10⁶) = 0.1256 kg/s
       = 7.54 kg/min = 452 kg/h
```

**耗水量**:

```
蒸汽能流量 = 3.14 × 0.85 = 2.67 MW
ṁ_water = 2.67 / 3.4 = 0.785 kg/s = 47.1 L/min
```

**汇总**:

| 项目 | 值 |
|------|-----|
| 目标出力 | 1 MW (t 魔力) |
| 总效率 | 31.8% |
| 耗煤量 | **7.54 kg/min** (≈ 0.126 个/s) |
| 耗水量 | **47.1 L/min** |
| 输入煤化学能 | 3.14 MW |

|------|---------|---------|--------|--------|--------|

### 效率排序分析

| 路线 | 能量链长度 | 总效率 | 说明 |
|------|-----------|--------|------|
| t (热交换机) | 最短 (热→热) | 31.8% | 热量即 t, 无需额外转换 |
| m (蒸汽轮机) | 中等 (热→机械→m) | 27.5% | 机械转换有摩擦和级间损失 |
| p (泄压阀) | 中等 (热→压力→p) | 25.3% | pV 功只占蒸汽能的一部分 |

### 水循环评估

三条线同时满负荷运行时:

| 项目 | 值 |
|------|-----|
| 总耗煤 | 25.8 kg/min (≈ 1547 kg/h) |
| 总耗水 | 160.9 L/min (≈ 9654 L/h) |
| 总魔力产出 | 3 MW (m + p + t 各 1MW) |

> 前期单线运行时, 耗水约 47-59 L/min。若采用冷凝回收 (乏汽→水→回锅炉), 耗水量可降至补充散逸损失 (~5%)。

## 1 L 水基准换算

> 以锅炉消耗 1 L (≈1 kg) 水为基准, 反推所有上下游物料与能量。
> 注意: 1 L 水在锅炉内吸收 Δh = 3.4 MJ 热焓变为 500°C / 10 MPa 蒸汽, 固定耗煤 0.16 kg。三条魔力路线的差异仅在于下游机器对这份蒸汽能的提取效率不同。

### 热力基础 — 锅炉 (共用)

| 项目 | 值 | 单位 |
|------|-----|------|
| 基准水量 | 1 | L (≈ 1 kg) |
| 产出蒸汽携带能量 | 3.4 | MJ |
| 耗煤化学能 | 3.4 / 0.85 = 4.0 | MJ |
| 耗煤量 | **0.16** | kg |

### 下游三条路线

| 机器 | 魔力类型 | 蒸汽能输入 | 魔力产出 | 总效率 | 耗煤量 |
|------|---------|-----------|---------|--------|--------|
| 蒸汽轮机 | m | 3.4 MJ | **1.10 MJ** | 27.5% | 0.16 kg |
| 泄压阀 | p | 3.4 MJ | **1.01 MJ** | 25.3% | 0.16 kg |
| 热交换机 | t | 3.4 MJ | **1.27 MJ** | 31.8% | 0.16 kg |

### 反向换算: 1 MW 魔力需要多少 L 水?

> 由 1 L 水产出魔力反推 1 MW (= 1 MJ/s) 需要的耗水速率, 即机器的「蒸汽消耗速度」。

| 机器 | 1 L 水产魔力 | 1 MW 需水速率 | 验证 (原文) |
|------|-------------|-------------|-------------|
| 蒸汽轮机 (m) | 1.10 MJ | **54.6 L/min** | 54.5 L/min ✓ |
| 泄压阀 (p) | 1.01 MJ | **59.3 L/min** | 59.3 L/min ✓ |
| 热交换机 (t) | 1.27 MJ | **47.2 L/min** | 47.1 L/min ✓ |

> 每条路线吃的是同一份蒸汽 (3.4 MJ / L), 但提出来的魔力不同: t 路线单位水产魔最多, p 路线最少。
